# Iosevka Nerd Font (4 styles)

The Serpantinum shell draws its icons and much of its text in "Iosevka Nerd
Font" and "Iosevka Nerd Font Propo", Regular and Bold only. Those four files
are kept here so a fresh install needs about 55 MB instead of the 1.1 GB Arch
package (`ttf-iosevka-nerd`), which ships every weight and italic the shell
never asks for. `install.sh` copies them to `/usr/local/share/fonts` (system-wide, so the
boot-time password prompt can use the same font).
